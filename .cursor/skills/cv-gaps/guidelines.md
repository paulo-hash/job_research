# Gap analysis

- Compare `data/experience.txt` to rows in `data/jobs.db` only.
- A gap is a phrase in the compare script output (`missing` / `thin`), never a skill you guessed.
- Do not claim the user already built a project you are recommending.
- Personal-project ideas must map to a listed gap. If the corpus is all "Staff ML research" and the user is a data-integration engineer, say so: title seniority / domain mismatch is a gap too.
- "Learn X" only if X appears in `missing` or `thin`. Prefer the skills with the most job hits.
- Do not tell them to put a planned project on the CV.
