# CV gaps report

Write in French. Numbers and skill names stay as in the JSON. Do not invent a missing skill that is not in `missing` / `thin`.

```markdown
# Gaps: expérience vs offres

Corpus: N offres dans `data/jobs.db` (date du rapport).

## Déjà couvert
- skill — k/N offres (preuve dans experience.txt)

## Couverture mince (1 mention)
- skill — k/N offres — où c’est écrit aujourd’hui — comment le renforcer

## Gaps (0 mention)
| Skill | Offres | Exemples |
| --- | --- | --- |
| rust | 4/N | Company — Title |

## Skills à apprendre
Priorité = nombre d’offres. 5 à 8 max. Pour chacune: pourquoi (les offres), niveau utile (lire / utiliser / concevoir), pas un cursus générique.

## Projets perso
3 à 5 idées. Chaque idée:
- comble 1–2 gaps du tableau
- faisable seul, publiable (repo)
- ce qui irait ensuite sur le CV (une bullet, au conditionnel: « si tu le livres »)
- ne pas le rédiger comme une expérience déjà faite

## Ce que le CV a déjà et que les offres demandent
Rappel court: ne pas négliger Python / TypeScript / etc. si le corpus les cite beaucoup.
```
